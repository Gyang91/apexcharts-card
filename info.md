# ApexCharts Card

A highly customizable graph card for Home Assistant's Lovelace UI, based on
[ApexCharts.js](https://apexcharts.com).

## Features

- Line, area, bar, scatter, pie, donut and radial bar chart types
- Multiple Y axes, annotations and color thresholds
- Statistics, `group_by` and aggregation functions, including calendar periods
  (day, week, month, quarter, year) and a time-weighted average
- Fast loading: websocket history, shared statistics cache, about 1.5 MB
- Brush charts, configuration templates and experimental features

See the [README](https://github.com/Gyang91/apexcharts-card) for the full list of
configuration options.
